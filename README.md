# Dungeon
A dungeon builder/manager/roguelike game.

## Fire Emblem Three Houses Randomizer

`Fire Emblem Three Houses Randomizer.exe` in this repo is the standalone FE3H
randomizer. See [`fe3h-randomizer-tools/README.md`](fe3h-randomizer-tools/README.md)
for the batch scripts that run it and sort every randomized file into the
correct `romfs` patch folder structure automatically.
